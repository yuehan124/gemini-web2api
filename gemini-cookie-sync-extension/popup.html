Gemini Cookie Sync

Reads cookies, XSRF, and build metadata from the current Gemini session. Sync pushes them straight to your running gemini-web2api server, which updates gemini-auth.json and config.json.

Server

Ready.

Auto-sync needs a signed-in Gemini tab (or the page fetch to succeed) so it can read a fresh XSRF token. The generated file contains highly sensitive session data; do not share it or commit it to Git.
